# VoltGrid evidence ledger

Status date: 28 September 2026 (Asia/Calcutta)

This is a capture plan and audit ledger, not proof of deployment. At this P4 snapshot, no VoltGrid testnet receipt, hosted demo, public repository link, or video link was supplied. Every proof and public-link slot below is therefore `UNVERIFIED`. Do not change a slot to `VERIFIED` until the named source has been checked by a person.

The repository's current architecture uses a deterministic simulator and a trusted oracle for model readings. The product claim is consequently: **algorithmic pricing with an optional forecasting layer, simulated metering and a simulated treasury, and real MST Testnet transactions when a transaction has a successful receipt**. It is not a claim of utility or government endorsement, a verified carbon offset, a legal approval, or generic AI pricing.

## Evidence rules

- `UNVERIFIED` means no qualifying artifact is attached or linked yet.
- A local test is proof only when the named command is run against the current checkout and its output is recorded.
- A local demo observation is proof only when a clean browser run is recorded with a timestamp and screenshot or screen recording.
- A testnet proof must include the real transaction hash, `eth_getTransactionReceipt.status == 1`, the expected contract address, decoded event logs, and an opening MSTScan URL. A pending hash, read-only RPC response, or copied explorer URL is not proof.
- A screenshot can show UI state, but cannot replace a receipt for an on-chain claim.
- All placeholders intentionally use words such as `UNVERIFIED` and contain no hex-looking address or hash. Replace them only with values copied from the actual artifact.
- If a feature is not shipped, record `NOT SHIPPED - DO NOT CLAIM` instead of staging a screenshot or hash.
